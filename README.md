# Lucknow 3D — Virtual Heritage Experience 🏛️✨

An interactive 3D web experience showcasing the historic landmarks, timeless architecture, and royal heritage of Lucknow, India ("The City of Nawabs").

## 🌟 Highlights
- 🚇 **Lucknow Metro (The City Opens):** High-speed locked-scroll video scrub horizon.
- 🛕 **Hanuman Setu Temple:** Sacred sanctum gate reveal with divine light rays.
- 🏛️ **Bada Imambara 360°:** 3D interactive labyrinth (Bhool Bhulaiya) and the column-less Asafi Hall (1784 AD).
- 🕰️ **Hussainabad Clock Tower:** India's tallest clock tower with Victorian-Gothic and Awadhi architecture (1887 AD).
- 🛍️ **Hazratganj 3D Boulevard:** Heritage promenade, Janpath Chikankari, Love Lane, and Royal Cafe basket chaat.
- 💎 **Smart Round Transparent Header:** Active scroll spy navigation tracking sections smoothly.
- 📜 **Rich Awadh Culture Footer:** Authentic coordinates, cultural craft details, and smooth navigation links.

## 🛠️ Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS, Glassmorphism, CSS 3D Transforms
- **Animations:** Framer Motion, RequestAnimationFrame scroll scrub
- **Language:** TypeScript

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the project in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
